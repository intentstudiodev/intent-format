# comment · CM · folder `comments/`

> Generated by `mds build-kit` from `schema.json` — do not edit by hand.

One remark, attached from the cards it is about; its text lives only here.

**When to use.** A review remark or question about a card; attach it from that card's ## Comments. Excluded from export by default.

**Not to confuse with**
- **decision** — If it needs a choice between options, open a decision.

## Front matter

| Key | Required | Values |
|---|---|---|
| `standard` | yes | `MDStandard/1.0` — always the first key |
| `type` | yes | `comment` |
| `id` | yes | `CM000000`-style core (CM + 6 digits) — minted by `mds new`, never by hand |
| `name` | yes | the card name (no `[` `]`); title, references and filename slug derive from it |
| `status` | yes | status vocabulary below, or `—` |
| `author` | yes | Who wrote it (name or role). |
| `date` | no | pattern `^\d{4}-\d{2}-\d{2}$` — When it was written (authored value). |
| `origin` | no | `<kb>/<core>` — written by import |
| `x-*` | no | extension keys; kept untouched, always last |

Keys in this order. Unknown = `—` (never quoted); `version`-like values are quoted.

## Status

`Open` · `Resolved` — The only representation of a comment's state. Template: `Open`. status: — when there is no evidence for any value. Status only with evidence.

## Sections

| Section | Kind | Guidance |
|---|---|---|
| (text under the title) | required | The remark itself, directly under the title (and status line). |
| ## Links | optional | External links: - [title](url) · type: Design\|Code\|Doc\|Source\|Analytics\|Other. Source = evidence (inputs/ file or URL). Default relation: Link. |
| ## ⚙ Attached to | generated | Where this comment is attached. |

Body states: `—` alone = unknown (counted) · `none` alone = verified empty · a final `- —` / `N. —` list item = more items exist but are unknown. Never edit `⚙` sections or the `> ⚙` status line — run `mds regen`.

## Relations written on this type

| Relation | Written in | Targets | Qualifiers | Generated reverse |
|---|---|---|---|---|
| Link | ## Links (no prefix) | URL, or a path to a file in inputs/ | type: Design\|Code\|Doc\|Source\|Analytics\|Other | — |
