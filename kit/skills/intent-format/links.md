# Links and relations

> Generated by `intent-format build-kit` from `schema.json` — do not edit by hand.

## Reference atoms

| Atom | Shape | Meaning |
|---|---|---|
| bound | `[#<CORE> <Name>](<relative-path>[#<anchor>])` | resolves by core; name and path are courtesy — `intent-format regen` rewrites them |
| hand | `#<CORE>` | valid; `intent-format regen` upgrades it to bound on relation lines |
| placeholder | `[~ <Name>]` | should exist, does not yet; counted as unresolved |
| unknown | `—` | target unknown (blind spot) |

Never write rendered IDs (`#SC000006V1.0`) in references or front matter.

## Line shapes

- **relationLine**: `- <Relation>: <atom>[ · <key>: <value>]…[ — <note>]`
- **prefixlessLine**: `- <atom>[ · <key>: <value>]…[ — <note>]`
- **orderedLine**: `<n>. <atom>[ · <key>: <value>]…[ — <note>]`
- **twoSlotLine**: `- Edge: <atom> → <atom>[ · label: <text>][ — <note>]`
- **labelSlotLine**: `- Branch: <label> → <atom>[ · primary][ · rule: #RL…][ — <note>]`
- **textSlotLine**: `- Entry: <text>  |  - Outcome: <text>`
- **generatedLine**: `- ⚙ Prev: <atom>[ · variant: <name>]  |  - ⚙ Next: …`
- **titleLine**: `# <name> · #<CORE>`
- **statusLine**: `> ⚙ <rendered-id> · V<version> <lifecycle>[ · based on V<base>][ · new | unchanged | changed: <Part>, <Part>]`
- **subdocumentHeading**: `### [<glyph> ]<Name> · #<CORE>`
- **anchorLine**: `<a id="<core-lowercase>"></a>`
- **passportLine**: `<key>: <value>[ · <key>: <value>]…`
- **atoms**: `bound [#<CORE> <Name>](<relative-path>[#<anchor>]) · hand #<CORE> · placeholder [~ <Name>] · unknown —`
- **bodies**: `— alone = blind spot · none alone = verified none`

## Rules

- One edge per line; each relation is written at exactly one end; reverses are generated.
- In a section with a default relation, lines drop the prefix; writing the default prefix anyway is tolerated (info).
- Explicit prefixes are required in sub-documents and for Edge, Branch, Entry, Outcome and x-<slug> relations.
- A relation word outside this vocabulary in a relation context is reported; x-<slug> relations are preserved untouched.
- Qualifier values are plain text or a bare core (#RL000007), never a bound link; quote values containing " · ", "—" or "→".
- Notes (" — <text>") are short and never restate the target card.
- Repetition at several granularities (a screen and its step both using one API) is fine; generated sections dedupe.
